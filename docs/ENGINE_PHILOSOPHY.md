# Driftwood Engine Philosophy

Versão: 1.0

Data: 2026-07-30

---

# Visão

Driftwood não é um jogo tradicional.

É uma janela para um mundo vivo.

O usuário não controla o personagem.
O usuário observa.

O mundo deve continuar existindo mesmo quando ninguém está olhando.

---

# Princípios fundamentais

## 1. O mundo vem antes do jogador

O náufrago não existe para entreter o usuário.

Ele possui:

- necessidades próprias;
- desejos;
- medos;
- hábitos;
- memória;
- evolução.

O usuário é um observador.

---

## 2. Simulação e apresentação são separadas

A simulação controla:

- tempo;
- clima;
- ecologia;
- inteligência artificial;
- histórias;
- eventos.

A apresentação controla:

- gráficos;
- iluminação;
- animações;
- efeitos;
- áudio.

Um sistema nunca deve depender do outro.

---

## 3. A contemplação é o objetivo

Cada decisão técnica deve perguntar:

"Isso aumenta a sensação de observar um mundo real?"

Priorizar:

- atmosfera;
- detalhes;
- passagem do tempo;
- pequenas histórias;
- momentos raros.

Evitar:

- excesso de interface;
- interrupções;
- controles desnecessários.

---

# Direção visual

Driftwood deve parecer:

- uma pintura viva;
- uma animação contemplativa;
- um mundo pequeno, mas profundo.

A inspiração vem de:

- protetores de tela clássicos;
- animações cinematográficas;
- livros ilustrados;
- natureza.

---

# Regras técnicas

## Nunca fazer

- Misturar renderização com lógica de jogo.
- Colocar regras da IA dentro do renderer.
- Criar dependência entre sistemas independentes.
- Sacrificar estabilidade por efeitos visuais.

---

## Sempre fazer

- Código simples de entender.
- Sistemas independentes.
- Conteúdo configurável.
- Melhorias incrementais.
- Preservar compatibilidade com saves.

---

# Filosofia de evolução

Driftwood deve crescer como uma floresta.

Não como uma construção.

Novos elementos devem nascer naturalmente:

- novos animais;
- novas histórias;
- novos fenômenos;
- novos ambientes.

Cada adição deve parecer que sempre pertenceu ao mundo.

---

# Frase guia

"Não estamos criando um jogo para ser vencido.
Estamos criando um mundo para ser descoberto."
